## Every custom function and method

| Callable | Inputs -> return | Responsibility / side effects |
| --- | --- | --- |
| Camera.__init__ | no explicit inputs -> new instance | Construct Picamera2; can fail if unavailable |
| Camera.__enter__ | instance -> instance | Configure/start/warm camera; close on startup failure |
| Camera.read | instance -> BGR array | Capture a new processed image; convert channel order |
| Camera.__exit__ | instance + exception details -> None | Close camera; do not suppress the original exception |
| Settings generated initializer | color, min_pixels, clean -> instance | Generated by dataclass, stores values then validates |
| Settings.__post_init__ | instance -> None | Reject unsupported color or nonpositive/noninteger area |
| region_name | horizontal centroid, image width -> str | Assign image third; no hardware or files |
| analyze | BGR array, Settings -> image, mask, dict | Process and draw on a copy; preserve input array |
| area-ranking lambda | component index -> area | Tell max which connected component wins |
| demo_image | position string -> BGR array | Make a known synthetic image in memory |
| save_image | Path, array -> None | Write temporary PNG then replace displayed file |
| write_page | output directory Path -> None | Write an HTML viewer for saved results |
| run.main | command-line arguments -> None | Validate settings; own source; loop; save observations |
| play.main | no inputs -> None | Run three known scenes and print observations |
| choose_nearest_center (optional) | stats, centers, width, min_pixels -> index or None | Alternative selection policy in EXTENSIONS.md |

The web viewer also contains a JavaScript function, update(), which refreshes image URLs and fetches latest.json. It is presentation code, not Python perception code. The lesson notebook's JavaScript saves typed notes; it does not run camera commands.

## Computer vision terms in plain language

**BGR/RGB:** two channel order conventions, not different physical colors. **HSV:** another numerical representation useful for certain color rules. **Binary mask:** yes/no pixel selection. **Connected component:** a group of touching selected pixels. **Centroid:** mean position of selected pixels in a component. **Bounding box:** rectangle enclosing a component. **Morphological opening:** erosion followed by dilation using a small neighborhood. **Threshold:** a decision boundary chosen for a quantity. **Inference:** applying a model or procedure to an input; our core rule has no learned neural network. **Training:** adjusting model parameters using data and an objective; changing min_pixels by hand is tuning, not neural-network training. **False positive:** a retained region that does not match your intended target definition. **False negative:** an intended target that is missed. **Contract:** agreed input/output meaning across modules.

## Troubleshooting by layer

| Symptom | Layer to check | Action |
| --- | --- | --- |
| No module named vision | Shell location | cd to the student folder |
| No module named cv2 | Python environment | Use Pi system Python; install missing OS packages only |
| Camera busy | Device ownership | Stop the known preview/Vilib process before retrying |
| Picamera2 cannot find camera | Camera stack/hardware | Reuse your previously working camera check; power off before touching ribbon |
| Original looks fine but mask is empty | Processing | Check selected color, lighting, HSV bounds and minimum area |
| Huge unexpected box | Task definition | Inspect blue background or connected objects |
| Browser cannot connect | Network/display | Verify server terminal, port, IP and same trusted LAN |
| Browser looks frozen | Time/display | Check timestamp, frame count and whether capture ended |
| FileExistsError | Evidence storage | Use a new output folder |
| JSON null distance | Correct output | This module does not measure range |
